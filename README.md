## About erxis

erxis is your personal shopping agent. Pin any product page while browsing and tell it what to watch for  a restock, a price drop, a new release  and erxis keeps an eye on it for you. When something changes, it reasons about whether the change actually matches what you asked for, then emails you (or someone you set it up for) with the update.

## Features

- [ ] Browser extension to pin and watch any page
- [ ] Natural-language watch instructions ("tell me when this restocks")
- [ ] Set up watches for someone else, not just yourself
- [ ] Automated page monitoring and change detection
- [ ] AI-reasoned relevance filtering before alerting
- [ ] Email delivery with reply-based watch control
